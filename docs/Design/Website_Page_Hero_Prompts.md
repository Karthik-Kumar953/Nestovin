# Nestovin website: page hero image prompts

**Updated:** 25 Nov 2026. This file adds one hero photograph per page. It sits next to `Website_Image_Prompts.md`, so use that file's rules, palette, uniforms and character sheets (sections 1 to 3).

Every page now opens the way the home page does. The photograph covers the whole first screen, a brand-green overlay rises from the bottom, and the headline and paragraph sit on top of it at the bottom left.

**You do not need to tell the code team.** Save each file in `apps\site\public\site\` with the exact name below, and the page uses it on the next build. Until then, each page shows an existing photo.

---

## 1. Rules for a hero photo (read these first)

The words and the green overlay cover the **bottom-left part** of every hero, and phones crop the photo to its middle. So every hero photo needs this layout:

1. **Format:** 16:9, landscape, upscaled to 2K (about 2752 × 1536). JPG. No separate mobile crop is needed.
2. **Faces in the top half.** Every face and the main action sit in the **upper 55%** of the frame.
3. **Calm bottom.** The **bottom 35%** is quiet, simple surface: floor, counter top, path, lawn, or a soft out-of-focus foreground. Nothing important happens there, because the green overlay and the headline sit on it.
4. **Main person in the middle-right.** Keep the main person between **40% and 75% across** the frame. Phones show only the middle, so the person must not be at the far edge.
5. **Calm bottom-left corner.** The bottom-left quarter stays simple and mid-toned (no bright white window, no busy pattern), so white words read clearly on it.
6. **Light:** one named light source, soft and natural. No harsh midday sun.
7. **No readable text.** The uniform carries only the plain white embroidered house shape. ID cards stay blurred or turned away.
8. Use the **negative prompt** from `Website_Image_Prompts.md` section 1 on every image. Add the **character sheets** as Ingredients where the table says so.
9. Pick the best of four, then check: hands, utensils, door frames, faces. Reject anything warped.
